Подарки в Crafter.

Один серверный ключ: каталог и модели, лоты игроков и подключённого маркета, покупка, продажа и передача подарков. Баланс и подарки лежат на вашем аккаунте Crafter.

Паки в API не участвуют. Карточные паки — внутренняя механика Crafter. Подарки, выпавшие из паков и ставшие обычными подарками аккаунта, API видит как все остальные.

01Что даёт API

Каталог

Коллекции, модели с картинками, фоны, узоры и минимальные цены.

Единый маркет

Лоты игроков Crafter и подключённого маркета (Portals, Thermos) в одном ответе, отсортированные по цене.

Баланс аккаунта

Читайте баланс и тратьте его на покупки — так же, как в самом приложении.

Свои подарки

Смотрите инвентарь, выставляйте на продажу, снимайте с продажи и передавайте другим игрокам.

Куда идти. Базовый адрес: {{ base }}. Ответы всегда в JSON, кодировка UTF-8, время в секундах Unix (UTC).

02Как подключиться

Подключение занимает несколько минут. Ключ привязан к одному аккаунту Telegram, поэтому для проекта удобно завести отдельный аккаунт.

  1. Откройте Crafter один раз. Запустите приложение в Telegram с аккаунта, который будет использовать API. Ключ выдаётся только тем, кто хотя бы раз заходил в приложение.
  2. Отправьте боту команду /api. Бот @{{ bot }} пришлёт сообщение с ключом. Он скрыт «спойлером»: тапните, чтобы увидеть, долгое нажатие копирует.
  3. Сохраните ключ на сервере. Храните его в переменных окружения или менеджере секретов. Ключ выглядит так: CRT/aB3dE5fG7hJ9kL1mN3pQ5rS7tU9vW1xY3zA5bC7d — префикс CRT/ и 40 символов (буквы и цифры).
  4. Пополните баланс аккаунта. Покупки списывают GRAM с баланса того аккаунта, которому принадлежит ключ. Баланс видно в приложении и в GET /account.
  5. Сделайте первый запрос. Проверьте ключ командой ниже. Если вернулся "ok": true, всё работает.
curl {{ base }}/account \
  -H "Authorization: Bearer CRT/ваш_ключ"
Нужен новый ключ? Если ключ утёк или потерян, напишите в поддержку @crafter_support: ключ заменят, старый перестанет работать сразу. Любой повторный /api показывает тот же ключ, пока его не заменили.

03Авторизация

ЗаголовокЗначениеКогда нужен
AuthorizationBearer CRT/…В каждом запросе
Content-Typeapplication/jsonВ POST-запросах
Idempotency-KeyУникальный номер операцииВ каждом POST, см. раздел

Правила

  • Только HTTPS и только с сервера. Запросы из браузера с заголовком Origin отклоняются: ключ нельзя встраивать в сайт или мобильное приложение.
  • Ключ даёт доступ к одному аккаунту: его баланс, покупки и подарки. Чужие аккаунты, админ-функции и вывод средств за пределы Crafter ему недоступны.
  • Права ключа: read, buy, sell, transfer. Список приходит в GET /account.
  • Заблокированный аккаунт теряет доступ к API.

04Деньги, ID и форматы

Деньги

Все суммы в GRAM. Каждая цена в ответе приходит в двух полях: price — десятичная строка ("12.5") и price_nano — целое число в нано-единицах строкой ("12500000000", 1 GRAM = 1 000 000 000).

В запросах передавайте сумму либо строкой в GRAM ("price": "12.5"), либо в нано ("price_nano": "12500000000"). Никогда не используйте числа с плавающей точкой — только строки.

Идентификаторы

ПолеПримерОткуда берётся
lot_id лота игрокаcrafter-9f2c4a…GET /lots, source: "crafter"
lot_id лота маркетаm.snowmittens.8f1d…GET /lots, source: "market"
gift_idthermos-7a1c…GET /inventory или чек покупки
collectionsnowmittensGET /collections (можно и название)
telegram_id"123456789"Числовой Telegram ID получателя
Не путайте. number — порядковый номер подарка внутри коллекции (#12345), а gift_id — идентификатор в вашем инвентаре. В операциях используйте gift_id и lot_id.

05Чтение данных

Все эти запросы — GET. Лимит один и тот же: {{ limit }} запросов за {{ window }} секунд на ключ.

ПутьЧто возвращает
/accountБаланс, права ключа, режим работы
/collectionsКоллекции с минимальной ценой
/models?collection=snowmittensМодели, фоны, узоры и картинки
/lots?collection=snowmittens&page=1Лоты Crafter и маркета вместе
/inventory?before=…Ваши подарки, по 50 за запрос
/gifts/{gift_id}Ваш подарок или открытый лот Crafter
/operations/{id}Результат операции по её Idempotency-Key
GET/accountправо read

Показывает аккаунт, которому принадлежит ключ, его баланс и режим работы сервиса (test или work, см. раздел).

{
  "ok": true,
  "account": { "id": "123456789", "name": "Anna", "username": "anna_dev" },
  "balance": "142.5",
  "balance_nano": "142500000000",
  "currency": "GRAM",
  "new_year_balls": 320,
  "rights": ["read", "buy", "sell", "transfer"],
  "mode": "work"
}
GET/collectionsправо read

Каталог коллекций. floor — минимальная цена на рынке в GRAM (может быть null, если лотов нет). Цены подключённого маркета пересчитаны из TON по текущему курсу сервиса.

{
  "ok": true,
  "count": 123,
  "collections": [
    { "id": "snowmittens", "name": "Snow Mittens", "image": "https://…", "floor": "9.4", "floor_nano": "9400000000" }
  ]
}
GET/models?collection=snowmittensправо read

Модели коллекции с картинками. Если у модели нет картинки, preview_url равен null — не подставляйте картинку другой модели.

{
  "ok": true,
  "collection": { "id": "snowmittens", "name": "Snow Mittens" },
  "models": [ { "name": "Frost Fingers", "preview_url": "https://…", "floor": "10.5" } ],
  "backdrops": [ { "name": "Black", "rarity": 10 } ],
  "symbols": [ { "name": "Star", "preview_url": "https://…" } ]
}
GET/lotsправо read

Главный запрос для витрины: лоты игроков Crafter и подключённого маркета в одном списке. Цена всегда точная, как при покупке.

ПараметрОписание
collectionОбязательный. ID или название коллекции.
modelТолько эта модель.
numberТолько подарок с этим номером.
sourceall (по умолчанию), crafter — только лоты игроков, market — только подключённый маркет.
sortprice_asc (по умолчанию) или price_desc.
page, limitСтраница с 1 и размер страницы до 50 (по умолчанию 20).

  "collection": { "id": "snowmittens", "name": "Snow Mittens" },
  "page": 1, "limit": 20, "total": 37, "has_more": true,
  "lots": [
    {
      "lot_id": "m.snowmittens.8f1d2c…",
      "source": "market", "market": "Thermos",
      "collection": "Snow Mittens", "number": 40411,
      "model": "Frost Fingers", "backdrop": "Black", "symbol": "Star",
      "image": "https://…", "price": "9.4", "price_nano": "9400000000"
    },
    {
      "lot_id": "crafter-9f2c4a7b…",
      "source": "crafter", "market": "Crafter",
      "collection": "Snow Mittens", "number": 12877,
      "model": "Frost Fingers", "price": "9.9", "price_nano": "9900000000"
    }
  ]
}
Защита от неверных цен. Лоты подключённого маркета, цена которых намного ниже минимальной цены коллекции, считаются ошибкой данных и в список не попадают.
GET/inventoryправо read

Ваши подарки (без паков и тестовых подарков). За один запрос приходит до 50 штук. Если подарков больше, в ответе есть next — передайте его в параметре before, чтобы получить следующую страницу.

{
  "ok": true,
  "gifts": [
    { "gift_id": "thermos-7a1c…", "name": "Snow Mittens", "number": 40411, "model": "Frost Fingers",
      "backdrop": "Black", "symbol": "Star", "image": "https://…", "status": "unlisted", "listing_price": null }
  ],
  "next": null
}

status: unlisted — лежит в инвентаре, listed — выставлен на продажу (тогда listing_price показывает цену).

GET/gifts/{gift_id}право read

Возвращает ваш подарок ("kind": "own") или открытый лот игрока Crafter ("kind": "lot", id вида crafter-…). Лоты подключённого маркета ищите через /lots.

GET/operations/{operation_id}право read

Сохранённый результат операции по её Idempotency-Key. Используйте после обрыва связи, прежде чем что-либо повторять (см. повторы).

{
  "ok": true,
  "operation_id": "order-2026-12-01-0001",
  "status": "done",
  "method": "buy",
  "result": { "lot_id": "crafter-9f2c4a7b…", "state": "done", "price": "9.9" }
}

06Покупка, продажа и передача

Все операции — POST с JSON-телом и обязательным заголовком Idempotency-Key.

ПутьПравоТело запроса
/buybuy{"lot_id":"crafter-9f2c…","max_price":"10"}
/sellsell{"gift_id":"thermos-7a1c…","price":"12.5"}
/unlistsell{"gift_id":"thermos-7a1c…"}
/transfertransfer{"gift_id":"thermos-7a1c…","telegram_id":"123456789"}

Комиссии

  • Продажа на маркете Crafter облагается стандартной комиссией маркета, её платит продавец (она показывается в приложении при выставлении).
  • /transfer бесплатный. Он работает только внутри Crafter: получатель должен хотя бы раз открыть приложение.
  • При покупке покупатель платит ровно цену лота.
POST/buyправо buy

Покупает лот игрока или лот подключённого маркета — по lot_id из /lots. Параметр max_price — это максимум, который вы готовы заплатить. Если цена лота к моменту покупки выше, покупка не выполняется, деньги не списываются, а ответ содержит код price_changed.

curl -X POST {{ base }}/buy \
  -H "Authorization: Bearer CRT/ваш_ключ" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: order-2026-12-01-0001" \
  -d '{"lot_id":"crafter-9f2c4a7b…","max_price":"10"}'
{
  "ok": true,
  "operation_id": "order-2026-12-01-0001",
  "status": "done",
  "result": {
    "lot_id": "crafter-9f2c4a7b…",
    "state": "done",
    "price": "9.9", "price_nano": "9900000000",
    "gift": { "gift_id": "…", "name": "Snow Mittens", "number": 12877, "model": "Frost Fingers" },
    "balance": "132.6"
  }
}
Подарок подключённого маркета выкупается на маркете и попадает в ваш инвентарь после доставки; это может занять немного времени. До этого статус операции может быть processing — проверяйте /operations/{id}.
POST/sellправо sell

Выставляет ваш подарок на маркет Crafter или меняет цену уже выставленного. Ответ state: "accepted" означает, что цена сохранена. Подарок может быть куплен сразу, а может ждать покупателя — следите за GET /inventory.

{ "gift_id": "thermos-7a1c…", "price": "12.5" }
{ "ok": true, "operation_id": "…", "status": "done",
  "result": { "gift_id": "thermos-7a1c…", "state": "accepted", "price": "12.5", "price_nano": "12500000000" } }
POST/unlistправо sell

Снимает ваш подарок с продажи. Работает только на ваших выставленных подарках.

{ "gift_id": "thermos-7a1c…" }
POST/transferправо transfer

Передаёт ваш невыставленный подарок другому игроку Crafter по его Telegram ID. Получатель должен хотя бы раз открыть приложение (иначе ошибка recipient_not_found) и иметь @username в Telegram (иначе recipient_no_username).

{ "gift_id": "thermos-7a1c…", "telegram_id": "123456789" }
{ "ok": true, "operation_id": "…", "status": "done",
  "result": { "gift_id": "thermos-7a1c…", "state": "done", "telegram_id": "123456789", "fee": "0" } }

08Idempotency-Key

Каждая операция записи (/buy, /sell, /unlist, /transfer) требует уникальный Idempotency-Key. Это страховка от двойных покупок: если запрос оборвался, вы можете безопасно отправить его ещё раз с тем же ключом, и сервер вернёт сохранённый результат вместо новой операции.

  • Формат: 16–80 символов — латинские буквы, цифры, _ и -. Подойдёт UUID.
  • Ключ уникален в пределах аккаунта и остаётся действительным после замены API-ключа.
  • Один и тот же Idempotency-Key с другим телом или другим методом даёт 409 conflict.
  • Сохраняйте номер и тело запроса до отправки — тогда его всегда можно повторить.
# Python
import uuid, requests
op = str(uuid.uuid4())          # сохраните op в своей базе до отправки
r = requests.post("{{ base }}/buy",
    headers={"Authorization": "Bearer " + KEY, "Idempotency-Key": op},
    json={"lot_id": lot_id, "max_price": "10"}, timeout=30)
print(r.status_code, r.json())
// Node.js 18+
const op = crypto.randomUUID();
const r = await fetch("{{ base }}/buy", {
  method: "POST",
  headers: { Authorization: "Bearer " + KEY, "Content-Type": "application/json", "Idempotency-Key": op },
  body: JSON.stringify({ lot_id, max_price: "10" }),
});
console.log(r.status, await r.json());

09Повторы и неопределённый результат

  1. Перед отправкой сохраните Idempotency-Key и тело запроса.
  2. Если ответ не пришёл (таймаут, обрыв), не создавайте новую операцию. Сначала спросите GET /operations/{id}.
  3. Если там 404, отправьте исходный запрос ещё раз с тем же ключом и тем же телом.
  4. Новый ключ допустим, только когда операция завершилась с ошибкой failed и вы исправили запрос.
  5. Статус review (HTTP 503) значит, что результат уточняется. Новую операцию не создавайте: смотрите /operations/{id} или обратитесь в поддержку @crafter_support.

10Ошибки и статусы

Ошибка всегда выглядит одинаково: {"ok": false, "error": "понятный текст", "code": "машинный_код"}. Для операций она приходит внутри result.

HTTP / statusЧто означает и что делать
200 · doneОперация выполнена, результат сохранён.
202 · processingОперация ещё выполняется. Опрашивайте /operations/{id}, не создавайте новую.
400 · failedНеверный запрос: проверьте code и error. Повторять можно только с новым ключом и исправленными данными.
401Нет или неверный ключ, ключ заменён.
403Запрос из браузера (есть Origin), аккаунт заблокирован или недостаточно прав.
404Коллекция, лот, подарок или операция не найдены. Лот мог быть продан.
409 · conflictIdempotency-Key уже использован с другим запросом.
409 · failedОперация отклонена по существу: price_changed, недостаточно баланса, лот недоступен.
429Слишком много запросов. Подождите заголовок Retry-After (10 секунд).
503 · reviewРезультат неизвестен. Не повторяйте с новым ключом, проверьте /operations/{id}.

11Лимиты

  • Частота: до {{ limit }} запросов за {{ window }} секунд на один ключ. При превышении приходит 429 и заголовок Retry-After.
  • Страницы: до 50 элементов в /lots и /inventory.
  • Покупки: действуют обычные правила Crafter: нужен достаточный баланс, а подарок должен быть ещё в продаже.
  • Кэш: список лотов подключённого маркета обновляется регулярно, но может отставать на секунды. Окончательную цену проверяет сам /buy.

12Тестовый и рабочий режим

Crafter работает в одном из двух режимов, он указан в поле mode ответа /account.

РежимКак работает
testПокупки подарков маркета тестовые: подарки приходят в тестовый инвентарь и не выводятся за пределы Crafter. Удобно для отладки интеграции.
workПодарки подключённого маркета выкупаются по-настоящему и приходят в ваш инвентарь. В списке лотов игроков Crafter остаются только подарки, реально находящиеся у сервиса.
Отладьте интеграцию в тестовом режиме, а перед рабочим запуском проверьте покупку, повтор запроса с тем же Idempotency-Key и чтение /operations/{id}.

13Безопасность ключа

Никому не передавайте ключ. Он даёт полный доступ к аккаунту: любой, у кого он есть, может тратить баланс и передавать подарки. Команда Crafter и поддержка никогда не просят ключ. Если кто-то просит его — это мошенники.
  • Храните ключ только на сервере: в переменных окружения или менеджере секретов. Не кладите его в репозиторий, логи и клиентский код.
  • Не пишите ключ в чаты и скриншоты. В сообщении бота он скрыт «спойлером» именно для этого.
  • Если ключ мог утечь, сразу напишите в поддержку @crafter_support для замены: старый ключ перестанет работать мгновенно.
  • Используйте отдельный аккаунт под интеграцию и держите на нём только нужную сумму.

14Перед запуском

  1. Проверьте чтение. /account, /collections, /lots возвращают данные и ваш баланс.
  2. Проверьте покупку. Купите самый дешёвый лот с небольшим max_price и убедитесь, что подарок появился в /inventory.
  3. Проверьте повтор. Отправьте тот же запрос с тем же Idempotency-Key: ответ должен совпасть, баланс не должен измениться второй раз.
  4. Проверьте обрыв. Эмулируйте таймаут и убедитесь, что ваш код сначала читает /operations/{id}.
  5. Следите за лимитами. Обрабатывайте 429 и Retry-After.

15Вопросы

Можно ли управлять паками через API?

Нет. Паки — личная механика Crafter, их нет в API.

Почему /lots не показывает мой лот?

Вы видите лоты других игроков и маркета. Свои лоты смотрите в /inventory (статус listed).

Бот не выдаёт ключ.

Откройте приложение Crafter хотя бы один раз с этого же аккаунта и отправьте /api снова.

Где машиночитаемое описание?

/partner-api.openapi.json — OpenAPI 3.0, его можно загрузить в Postman или сгенерировать клиент.

Что, если цена на маркете выглядит слишком низкой?

Лоты, цена которых намного ниже минимальной цены коллекции, считаются ошибкой данных и скрываются.

Оффер на конкретный лот: {"lot_id":"crafter-9f2c…","price":"8.5","expiry":"day"}. Оффер на коллекцию: {"collection":"Lol Pop","model":"Mirage","price":"4","quantity":2}. Сумма резервируется на балансе до ответа, отзыва или окончания срока.

curl -X POST {{ base }}/withdraw \
  -H "Authorization: Bearer CRT/ваш_ключ" \

Ответ содержит withdrawal_id, status и комиссию. Подарок помечается как выводимый, релейер отправляет его вам в Telegram. Следите за GET /withdrawals: queued → confirmed; при отказе подарок и комиссия возвращаются, причина в поле reason.

08Вывод TON

GRAM с баланса ключа можно вывести в TON. Деньги уходят только на кошелёк, который владелец аккаунта подключил в приложении (Профиль → Кошелёк): адрес в запросе передать нельзя, поэтому ключ не может отправить деньги «на чужой адрес».

ПутьМетодЧто делает
/ton/walletGETПодключённый кошелёк и сеть
/ton/withdrawPOSTСоздать заявку на вывод, нужен Idempotency-Key, право withdraw
/ton/withdrawalsGETПоследние 30 заявок
/ton/withdrawals/{id}GETСтатус одной заявки
POST/ton/withdrawправо withdraw

Тело: gram — сумма в GRAM строкой, не меньше 0,01, с точностью до сотых (или gram_nano). Курс, минимум, максимум и суточный лимит такие же, как в приложении.

curl -X POST {{ base }}/ton/withdraw \
  -H "Authorization: Bearer CRT/ваш_ключ" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: ton-2026-12-01-0001" \
  -d '{"gram":"25.00"}'

Статусы заявки

statusЧто значит
queuedПринята, GRAM уже списаны, ждёт отправки (обычно до 20 секунд)
processingTON отправляются, транзакция ещё не подтверждена
doneTON на кошельке; в tx_url ссылка на транзакцию в tonscan (когда хеш уже известен)
cancelledНе отправлено, GRAM вернулись на баланс

Ошибки

  • 409 — нет подключённого кошелька, не хватает GRAM, превышен лимит одной операции или суточный лимит, вывод отключён.
  • 400 — неверная сумма (нужна точность 0,01).
  • 503 с code: review — результат неизвестен: прочитайте GET /operations/{Idempotency-Key} и не повторяйте запрос с новым ключом.

Повтор запроса с тем же Idempotency-Key и тем же телом возвращает сохранённый результат и никогда не создаёт второй вывод.
